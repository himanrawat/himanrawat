### ⚙️ How I work

```
  scope the useful slice  →  design the states  →  build in reviewable PRs  →  hand over the reasoning
```

- **Product first.** I start with the workflow and the riskiest assumption, not the model.
- **The interface around the model.** Latency, failure, review, and human handoff get designed, not left to a generic chat box.
- **Coding with agents.** I run contract-first parallel builds with Claude Code and Codex, with an integrator that typechecks, tests, lints, and builds.
